# ConsoleBased-Applications
Console based applications designed using core java
1)EMPLOYEE PAYROLL SYSTEM APPLICATION
    This is a menu-driven console application developed using Core Java. It allows users to perform CRUD operations on employee records. I used a custom Employee class to represent each employee and stored all employee objects in an ArrayList. The application uses a Scanner for user input, a switch statement for menu handling, and loops to search, update, and delete employee records."
2)QUIZ APPLICATION
    This is a console-based Quiz Application developed using Core Java. The objective of this project is to ask multiple-choice questions to the user, evaluate the answers, calculate the score, and finally display whether the user has passed or failed."
